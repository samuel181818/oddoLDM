Administración y Configuración

Cómo configurar la empresa, instalar módulos y dejar Odoo listo para trabajar.

Acceso al panel de administración

Después de la instalación y de haber creado la base de datos, accedemos a Odoo en http://localhost:8069. Iniciamos sesión con el usuario y contraseña que pusimos al crear la BBDD.

La pantalla principal muestra el listado de aplicaciones (apps) disponibles. Al ser una instalación nueva, prácticamente no hay nada activado todavía.

[CAPTURA 1] · Pantalla principal de Odoo recién instalado

Configuración de la empresa

Lo primero que se hace es configurar los datos de la empresa. Para ello vamos a Ajustes → Usuarios y empresas → Empresas. Allí seleccionamos la empresa por defecto ("My Company") y rellenamos los datos reales: nombre, dirección, CIF, logo, etc.

[CAPTURA 2] · Formulario de configuración de la empresa

Estos datos son importantes porque luego aparecen en facturas, presupuestos y todos los informes que se generen desde Odoo.

Instalación de módulos (Apps)

Odoo funciona por módulos. Por defecto vienen muy pocos activados, así que hay que instalar los que se necesiten. Para esta práctica he activado los siguientes:

  • CRM: para gestionar oportunidades y clientes.
  • Ventas: presupuestos, pedidos y facturación.
  • Inventario: control de almacén.
  • Contactos: agenda de clientes y proveedores.
  • Facturación: facturas y pagos.

Para instalar un módulo basta con ir a la sección de Aplicaciones, buscarlo y pulsar el botón Activar.

[CAPTURA 3] · Buscador de Apps con un módulo a punto de instalarse
Truco: al instalar un módulo, Odoo carga automáticamente las dependencias (otros módulos que necesita). Por ejemplo, al instalar Ventas también se instala Facturación.

Ajustes generales

En Ajustes → Ajustes generales se configuran cosas como la moneda, el idioma de la interfaz, el modo desarrollador, los métodos de pago o las opciones de cada uno de los módulos instalados.

[CAPTURA 4] · Pantalla de Ajustes generales

Para esta práctica he activado el modo desarrollador, porque permite ver opciones avanzadas y acceder a información técnica de cada registro, lo cual es útil para entender cómo funciona Odoo por dentro.

Creación de usuarios

Para que más personas puedan acceder al sistema, hay que dar de alta usuarios. Se hace desde Ajustes → Usuarios y empresas → Usuarios.

Al crear un usuario nuevo se le indica:

  1. Nombre y correo electrónico (el correo es lo que usará como login).
  2. Tipo de usuario: Interno, Portal o Público.
  3. Permisos en cada uno de los módulos instalados.
  4. Empresa (en caso de tener varias).
[CAPTURA 5] · Formulario de creación de un nuevo usuario

Cuando se guarda el usuario, Odoo le envía un correo con un enlace para que establezca su propia contraseña.

Copias de seguridad de la base de datos

Una parte importante de la administración es hacer copias de seguridad. Odoo permite hacerlas desde la pantalla de gestión de bases de datos (http://localhost:8069/web/database/manager).

[CAPTURA 6] · Pantalla de gestor de bases de datos

Desde ahí se puede:

  • Crear copias de seguridad (.zip) que incluyen tanto los datos como los archivos.
  • Restaurar una copia anterior.
  • Duplicar una base de datos (muy útil para hacer pruebas).
  • Eliminar bases de datos.
Recomendación: es buena idea hacer una copia de seguridad antes de instalar módulos nuevos o de hacer cambios importantes en la configuración.
