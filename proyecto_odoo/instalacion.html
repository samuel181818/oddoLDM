Instalación de Odoo Community

Pasos seguidos para instalar Odoo 17 Community en una máquina con Windows.

Requisitos previos

Antes de empezar con la instalación es importante comprobar que el equipo cumple unos mínimos. En mi caso he hecho la instalación en un portátil con las siguientes características:

  • Sistema operativo: Windows 10 (64 bits)
  • RAM: 8 GB
  • Espacio libre en disco: unos 4 GB
  • Conexión a internet (para la descarga)
Importante: Odoo necesita PostgreSQL como base de datos. El instalador de Windows ya lo instala automáticamente, por lo que no hay que descargarlo aparte.

Paso 1 · Descarga del instalador

Lo primero es ir a la web oficial de Odoo, en el apartado de Download, y elegir la versión Community para Windows. El archivo descargado tiene un nombre parecido a odoo_17.0.latest.exe y pesa unos 350 MB.

[CAPTURA 1] · Página de descarga de Odoo (web oficial)

Paso 2 · Ejecutar el instalador

Al hacer doble clic sobre el ejecutable, aparece el asistente de instalación. El primer paso pide seleccionar el idioma:

[CAPTURA 2] · Selección del idioma del instalador

A continuación se acepta el acuerdo de licencia (LGPLv3) y se elige el tipo de instalación. Yo he dejado la opción "All in One", que instala tanto el servidor de Odoo como PostgreSQL.

[CAPTURA 3] · Selección del tipo de instalación (All in One)

Paso 3 · Configuración de PostgreSQL

El asistente pide configurar el usuario y la contraseña de la base de datos. Por defecto crea el usuario openpg. Es importante anotar la contraseña porque luego hará falta si se quiere acceder directamente a la base de datos.

[CAPTURA 4] · Configuración del usuario y contraseña de PostgreSQL

Paso 4 · Carpeta de instalación

Se elige la ruta donde se va a instalar. Por defecto es C:\Program Files\Odoo 17.0. Yo la he dejado tal cual.

[CAPTURA 5] · Selección de la carpeta de instalación

A partir de aquí empieza la instalación propiamente dicha. Tarda unos cuantos minutos porque también instala PostgreSQL y todas las dependencias de Python que necesita Odoo.

[CAPTURA 6] · Progreso de la instalación

Paso 5 · Primer arranque

Una vez termina la instalación, el servicio de Odoo se inicia automáticamente. Al abrir el navegador y entrar en http://localhost:8069 aparece la pantalla para crear la primera base de datos:

[CAPTURA 7] · Pantalla de creación de la primera base de datos

Aquí hay que rellenar:

  • Master password: contraseña de administrador del sistema.
  • Database name: nombre que se le quiera dar (por ejemplo, empresa_demo).
  • Email y password: usuario administrador de esta base de datos.
  • Idioma y país: en mi caso Español y España.
  • Demo data: lo marco para tener datos de ejemplo y poder hacer pruebas.

Paso 6 · Comprobación final

Tras pulsar en Create database, Odoo carga la pantalla principal. Si llegamos aquí, la instalación ha sido un éxito.

[CAPTURA 8] · Pantalla principal de Odoo después de crear la base de datos

El siguiente paso es ir a Administración para empezar a configurar el sistema.
