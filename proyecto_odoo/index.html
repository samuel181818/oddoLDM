Bienvenido

Este sitio web ha sido desarrollado como parte de un proyecto de clase para el módulo de Sistemas de Gestión Empresarial. A lo largo de las distintas páginas vamos a ver qué es un SGE, qué tipos existen, sus ventajas, y se documentará todo el proceso de instalación, configuración y uso del sistema Odoo Community.

El objetivo es mostrar de forma práctica cómo se trabaja con una herramienta real de gestión empresarial: desde levantar el servicio en una máquina local hasta generar informes y exportar la información.

¿Por qué Odoo?

Odoo es una suite de aplicaciones de gestión empresarial de código abierto. Su versión Community es totalmente gratuita y permite gestionar prácticamente cualquier área de una empresa: ventas, compras, almacén, contabilidad, RRHH, fabricación, CRM, etc.

Lo hemos elegido por estos motivos:

  • Es gratuito y de código abierto.
  • Tiene una comunidad muy grande, hay muchísima documentación.
  • Su interfaz es moderna y bastante intuitiva.
  • Es modular: puedes activar solo lo que necesitas.
  • Se puede instalar en Windows, Linux y Mac sin demasiada complicación.
